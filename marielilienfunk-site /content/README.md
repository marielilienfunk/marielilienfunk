# Content-Ordner

Hier lädst du Bilder/Videos hoch — pro Projekt ein Ordner. Ich baue die Inhalte
dann in die jeweilige Projektseite ein.

## Struktur

- `inspiration/` — Screenshots, Moodboards, Referenzseiten für Gestaltung
  (Layout, Farben, Typografie, Stimmung der neuen Website)
- `about/` — Portraitfoto(s) für die About-Seite
- Ein Ordner pro Projekt (z. B. `chop-chop-bloom/`, `chateau-de-brantes/`, ...)
  — bereits mit den Namen aus dem aktuellen Portfolio angelegt
- `neues-projekt-beispiel/` — leerer Beispielordner: für ein komplett neues
  Projekt einfach einen Ordner mit dem gewünschten Namen anlegen

## Wie es weitergeht

1. Bilder/Videos in den passenden Ordner legen (am besten schon in der
   Reihenfolge, wie sie später auf der Seite erscheinen sollen).
2. Wenn ein Ordner Inhalte hat, sag mir kurz Bescheid, dann baue ich sie in
   die Seite ein.
3. Für "inspiration/": gerne auch kurze Notizen als .txt dazulegen (z. B.
   "diese Bildsprache", "diese Schrift", "so viel Weißraum wie hier").
